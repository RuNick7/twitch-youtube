AutoVOD

AutoVOD publishes segments of the Twitch broadcasts of zakvielchannel on YouTube, with the written permission of the streamer.

After each broadcast AutoVOD splits the recording by category and uploads each part as a private video to a single YouTube channel operated by RuNick7. A video is made public after YouTube has processed and checked it. Parts in which films or TV series are watched are not uploaded.

AutoVOD is a private tool and is not offered to the public. It uses YouTube API Services.

AutoVOD

AutoVOD публикует на YouTube фрагменты трансляций Twitch-канала zakvielchannel с письменного разрешения стримера.

После каждой трансляции AutoVOD делит запись по категориям и загружает каждую часть приватным роликом на один YouTube-канал, которым управляет RuNick7. Ролик становится публичным после того, как YouTube его обработал и проверил. Части, где смотрят фильмы или сериалы, не загружаются.

AutoVOD — частный инструмент, он не предлагается другим пользователям. Он использует сервисы YouTube API (YouTube API Services).
