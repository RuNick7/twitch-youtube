AutoVOD Privacy Policy

Last updated: October 1, 2026

AutoVOD is a private tool operated by RuNick7. It publishes segments of the Twitch broadcasts of zakvielchannel on a single YouTube channel operated by RuNick7, with the written permission of the streamer. AutoVOD is not offered to the public.

YouTube API Services

AutoVOD uses YouTube API Services. By using AutoVOD you agree to the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy.

Information AutoVOD accesses

When the owner of the YouTube channel authorizes AutoVOD with their Google account, AutoVOD receives access with the scope https://www.googleapis.com/auth/youtube and uses it only to:

  • read the ID and title of the authorized channel;
  • upload videos to that channel and set their title, description, tags, category and privacy status;
  • read the processing status, privacy status, duration and restrictions of the videos AutoVOD uploaded, and make those videos public.

AutoVOD does not access viewers' data, comments, subscribers, analytics, playlists or any other videos of the channel.

Information AutoVOD stores

  • the OAuth refresh token, encrypted;
  • the ID and title of the authorized channel;
  • the IDs and statuses of the videos AutoVOD uploaded.

This information is stored on a server controlled by the operator and is used only to upload and publish videos to the authorized channel. Video files pass through the server while being uploaded and are not stored.

Sharing

AutoVOD does not sell, share or transfer any of this information to third parties, and does not use it for advertising.

Revoking access and deleting data

You can revoke AutoVOD's access to your data at any time on the Google security settings page: https://security.google.com/settings/security/permissions.

After access is revoked, or on request, all stored information about your account is deleted within 7 days.

Contact

Questions about this policy: GitHub Issues.

Политика конфиденциальности AutoVOD

Последнее обновление: 1 октября 2026 года

AutoVOD — частный инструмент, которым управляет RuNick7. Он публикует фрагменты трансляций Twitch-канала zakvielchannel на одном YouTube-канале, которым управляет RuNick7, с письменного разрешения стримера. AutoVOD не предлагается другим пользователям.

Сервисы YouTube API

AutoVOD использует сервисы YouTube API (YouTube API Services). Пользуясь AutoVOD, вы соглашаетесь с Условиями использования YouTube. Как Google обращается с данными, описано в Политике конфиденциальности Google.

К каким данным AutoVOD получает доступ

Когда владелец YouTube-канала разрешает AutoVOD доступ через свой аккаунт Google, AutoVOD получает доступ с областью https://www.googleapis.com/auth/youtube и использует его только чтобы:

  • узнать ID и название подключённого канала;
  • загружать ролики на этот канал и задавать им название, описание, теги, категорию и доступ;
  • узнавать состояние обработки, доступ, длительность и ограничения роликов, загруженных AutoVOD, и делать эти ролики публичными.

AutoVOD не получает данных зрителей, комментариев, подписчиков, статистики, плейлистов и других роликов канала.

Какие данные AutoVOD хранит

  • токен обновления OAuth в зашифрованном виде;
  • ID и название подключённого канала;
  • ID и состояние роликов, загруженных AutoVOD.

Эти данные хранятся на сервере, которым управляет оператор, и используются только для загрузки и публикации роликов на подключённом канале. Видеофайлы проходят через сервер во время загрузки и не сохраняются.

Передача данных

AutoVOD не продаёт и не передаёт эти данные третьим лицам и не использует их для рекламы.

Отзыв доступа и удаление данных

Отозвать доступ AutoVOD к вашим данным можно в любой момент на странице настроек безопасности Google: https://security.google.com/settings/security/permissions.

После отзыва доступа или по запросу все сохранённые данные о вашем аккаунте удаляются в течение 7 дней.
