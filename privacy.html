AutoVOD Privacy Policy

Last updated: October 1, 2026

AutoVOD is a private tool operated by RuNick7. It publishes segments of the Twitch broadcasts of zakvielchannel on a single YouTube channel operated by RuNick7, with the written permission of the streamer. AutoVOD is not offered to the public. The operator controls it through a private Telegram bot.

YouTube API Services

AutoVOD uses YouTube API Services. By using AutoVOD you agree to be bound by the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy: http://www.google.com/policies/privacy.

Consent

Before AutoVOD gets access to a YouTube channel, the bot shows what AutoVOD will do with the channel and asks the channel owner to accept this Privacy Policy. Access is granted only after that, through Google sign-in (OAuth 2.0).

Information AutoVOD accesses

AutoVOD requests the scope https://www.googleapis.com/auth/youtube and uses it only to:

  • read the ID and title of the authorized channel;
  • upload videos to that channel as private and set their title, description, tags and category;
  • read the processing status, privacy status, duration and restrictions of the videos AutoVOD uploaded;
  • make those videos public (or unlisted, as configured by the owner): automatically after YouTube has processed a video and reported no problems, or when the owner presses a button in the bot;
  • create one playlist for each game category and add the videos AutoVOD published to the playlist of their category.

AutoVOD does not access viewers' data, comments, subscribers, analytics, or any other videos or playlists of the channel, and never asks for Google or YouTube passwords.

Information AutoVOD stores

  • the OAuth refresh token, encrypted;
  • the ID and title of the authorized channel;
  • the IDs and statuses of the videos AutoVOD uploaded;
  • the IDs of the playlists AutoVOD created;
  • the Telegram user ID of the operator, which is the only account the bot accepts commands from, and the IDs of the bot's own messages, so that it can update them. Messages from other Telegram users are ignored; their Telegram ID may appear in server logs, which are overwritten automatically.

This information is stored on a server controlled by the operator. Video files pass through the server while being uploaded and are not stored.

How the information is used and shared

The information is used only to upload and publish videos on the authorized channel and to report progress to the operator. Progress messages, which include video titles and links, are delivered to the operator through Telegram (Telegram Privacy Policy).

AutoVOD does not sell, share or transfer this information to any other party, does not use it for advertising, and does not allow third parties to serve content or advertisements.

Cookies and device data

AutoVOD does not store, access or collect information on or from users' devices or browsers, and does not place or read cookies or similar technologies. This website does not use cookies either. It is hosted on GitHub Pages, and GitHub may log visitors' IP addresses for security purposes (GitHub Privacy Statement).

Keeping data up to date

Every day AutoVOD checks that its access to the channel is still valid and refreshes the stored channel title, video statuses and playlists from YouTube. Records of videos and playlists that were deleted from YouTube are removed. Stored YouTube data is never kept for more than 30 days without being refreshed.

Revoking access and deleting data

The /disconnect command in the bot immediately revokes AutoVOD's access token at Google and deletes all stored information about the channel, its videos and playlists.

You can also revoke AutoVOD's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions. AutoVOD then deletes all stored information about the channel within 7 days (in practice at its next daily check).

A request to delete the stored data can also be sent through GitHub Issues; it is fulfilled within 7 days.

Deleting the data stored by AutoVOD does not delete anything on YouTube: the uploaded videos and the playlists stay on the channel. To delete them, use YouTube Studio.

Security

The refresh token is stored encrypted. Only the operator has access to the server and to the bot.

Changes to this policy

If AutoVOD starts to access or use data in a way that this policy does not describe, the policy will be updated first, and the channel owner will be asked to accept it again.

Contact

Questions or complaints about this policy and AutoVOD's privacy practices: GitHub Issues.

Политика конфиденциальности AutoVOD

Последнее обновление: 1 октября 2026 года

AutoVOD — частный инструмент, которым управляет RuNick7. Он публикует фрагменты трансляций Twitch-канала zakvielchannel на одном YouTube-канале, которым управляет RuNick7, с письменного разрешения стримера. AutoVOD не предлагается другим пользователям. Оператор управляет им через закрытый Telegram-бот.

Сервисы YouTube API

AutoVOD использует сервисы YouTube API (YouTube API Services). Пользуясь AutoVOD, вы соглашаетесь соблюдать Условия использования YouTube. Как Google обращается с данными, описано в Политике конфиденциальности Google: http://www.google.com/policies/privacy.

Согласие

Прежде чем AutoVOD получит доступ к YouTube-каналу, бот показывает, что AutoVOD будет делать с каналом, и просит владельца канала принять эту Политику конфиденциальности. Только после этого доступ выдаётся через вход в аккаунт Google (OAuth 2.0).

К каким данным AutoVOD получает доступ

AutoVOD запрашивает область https://www.googleapis.com/auth/youtube и использует её только чтобы:

  • узнать ID и название подключённого канала;
  • загружать на этот канал приватные ролики и задавать им название, описание, теги и категорию;
  • узнавать состояние обработки, доступ, длительность и ограничения роликов, загруженных AutoVOD;
  • делать эти ролики публичными (или доступными по ссылке, как настроил владелец): автоматически, когда YouTube обработал ролик и не нашёл проблем, или по кнопке владельца в боте;
  • создавать по плейлисту на каждую игровую категорию и добавлять в него опубликованные AutoVOD ролики этой категории.

AutoVOD не получает данных зрителей, комментариев, подписчиков, статистики, других роликов и плейлистов канала и никогда не запрашивает пароли от Google или YouTube.

Какие данные AutoVOD хранит

  • токен обновления OAuth в зашифрованном виде;
  • ID и название подключённого канала;
  • ID и состояние роликов, загруженных AutoVOD;
  • ID плейлистов, созданных AutoVOD;
  • Telegram ID оператора — единственного аккаунта, от которого бот принимает команды, — и ID собственных сообщений бота, чтобы их обновлять. Сообщения других пользователей Telegram бот игнорирует; их Telegram ID может попасть в журналы сервера, которые автоматически перезаписываются.

Эти данные хранятся на сервере, которым управляет оператор. Видеофайлы проходят через сервер во время загрузки и не сохраняются.

Как данные используются и кому передаются

Данные используются только для загрузки и публикации роликов на подключённом канале и для отчётов оператору. Сообщения о ходе работы с названиями роликов и ссылками доставляются оператору через Telegram (Политика конфиденциальности Telegram).

AutoVOD не продаёт и не передаёт эти данные другим лицам, не использует их для рекламы и не позволяет третьим лицам показывать контент или рекламу.

Cookie и данные устройств

AutoVOD не хранит, не получает и не собирает информацию на устройствах или в браузерах пользователей и не использует cookie и похожие технологии. Этот сайт тоже не использует cookie. Он размещён на GitHub Pages, и GitHub может записывать IP-адреса посетителей в целях безопасности (заявление GitHub о конфиденциальности).

Актуальность данных

Каждый день AutoVOD проверяет, что доступ к каналу ещё действует, и обновляет сохранённые название канала, состояние роликов и плейлисты по данным YouTube. Записи о роликах и плейлистах, удалённых с YouTube, стираются. Данные YouTube никогда не хранятся дольше 30 дней без обновления.

Отзыв доступа и удаление данных

Команда /disconnect в боте сразу отзывает токен доступа AutoVOD в Google и удаляет все сохранённые данные о канале, его роликах и плейлистах.

Отозвать доступ AutoVOD можно и в любой момент на странице настроек безопасности Google: https://security.google.com/settings/security/permissions. Тогда AutoVOD удаляет все сохранённые данные о канале в течение 7 дней (на деле — при ближайшей ежедневной проверке).

Запрос на удаление сохранённых данных можно также отправить через GitHub Issues; он выполняется в течение 7 дней.

Удаление данных, которые хранит AutoVOD, ничего не удаляет на YouTube: загруженные ролики и плейлисты остаются на канале. Удалить их можно в YouTube Studio.

Безопасность

Токен обновления хранится в зашифрованном виде. Доступ к серверу и боту есть только у оператора.

Изменения политики

Если AutoVOD начнёт получать или использовать данные так, как эта политика не описывает, сначала будет обновлена политика, и владельца канала попросят принять её заново.

Связь

Вопросы и жалобы об этой политике и обращении AutoVOD с данными: GitHub Issues.
